## Suggested upstream contribution units

### A — Scientific selective WASM recipe/package tests

Commit `526e9d081e5bb95275bd12a4a085627576d7eaa0`:
`build(wasm): support selective scientific packages and preserve notices`.

- `js/build.mjs` accepts explicit `--no-default-features --features netcdf-hdf5`,
  using the existing Cargo feature, one single-threaded module and `--locked`.
- No new official preset or default export expansion. Standard full/core/load
  behavior stays available; selective packages advertise only their actual modules.
- Selective output refuses an existing directory to avoid stale variant assets.
- Project LICENSE, NOTICE, and LICENSE-THIRD-PARTY.md are packaged. The third-party
  inventory is the existing all-feature conservative superset, not a minimal SBOM.
- Matching WASM declarations are explicitly included; wasm-pack generates them
  but its default npm file list omitted them during actual inspection.
- New `js/tests/build.test.mjs` has seven tool-independent packaging regressions.
- Recipe and limitations: `docs/scientific-wasm-build.md`, `js/README.md`.

### C — Remove redundant owned input copy

Commit `ea7213008abebe3bf0ebadaa018743e74d754c0c`:
`perf(multidim): retain owned input without redundant payload clone`.

- `multidim::open_bytes_owned(Vec<u8>)` retains owned input through shared storage.
  Existing borrowed `open_bytes(&[u8])` remains compatible.
- Both JS byte-input branches pass the converted Vec into the owned path.
- HDF5 userblocks use bounded offset storage over the retained input; encoded
  bytes stay alive while selected arrays/views retain their Arc ownership.
- Raw packed semantics, output typed-array copies, and lazy numeric reads unchanged.
- Rust regressions cover classic NetCDF, HDF5 userblocks at 0/512/1024/4096,
  malformed/truncated inputs, retained views, shared storage identity, and lazy I/O.
- `crates/terrio/tests/data/multidim-userblock.h5` is independently generated by
  h5py with a real producer-written 512-byte userblock and base addresses.

This removes one redundant payload clone, not all input copies. JS-to-WASM still
copies. Pinned BytesStorage converts Vec to Arc<[u8]> with another copy. Owned
input retains the userblock allocation; borrowed input can omit userblock bytes.
Peak allocations/RSS were not measured; do not claim a quantified peak-memory win.

# ras2fim-viewer-wasm — live demo

Generated by `pipeline/build_netcdf_site.py` on the `main` branch. Do not edit
here; this branch is replaced wholesale on each deploy.

The page reads ras2fim-2d NetCDF **directly in the browser** with h5wasm, in a
Web Worker. There is no tile server and no conversion step — the `.nc` files
under `data/` are byte-for-byte as ras2fim-2d wrote them.

`?verify=1` runs the retained dense renderer alongside the sparse one and
asserts they agree byte for byte.

Sample model output: [andycarter-pe/ras2fim-2d](https://github.com/andycarter-pe/ras2fim-2d)
